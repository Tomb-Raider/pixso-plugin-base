# Читалка .pix

Показывает, как устроен файл Pixso, без самого Pixso: дерево слоёв, ключи
компонентов и родные имена свойств автолейаута. Полезна, когда плагин записывает
свойство, а оно не применяется: в файле видно, как Pixso называет его на самом
деле (так нашлись `stackChildCounterSizing` и остальные `stack*`)

```bash
node read-pix.js макет.pix                 # дерево страниц
node read-pix.js макет.pix "Table S"       # поддерево узла по имени
node read-pix.js макет.pix --keys          # componentKey всех мастеров
```

Нужен Node 22.15 или новее (в нём есть `zlib.zstdDecompressSync`) и команда
`unzip`. Больше ничего ставить не надо

Как устроен формат: .pix это zip, внутри документ и схема в формате kiwi.
Документ сжат zstd, узлы лежат плоским списком со ссылкой на родителя.
`kiwi.js` здесь свой минимальный разборщик схемы и сообщений
